# 🎓 Campus Placement Management System

Welcome to the **Campus Placement System** project! 

## 🚀 Project Roadmap

Each folder in this repository represents a different phase of the application's architecture.

| Phase | Technology Stack | Status | Description |
| :--- | :--- | :--- | :--- |
| **[Phase 1: JDBC](./JDBC)** | Java, MySQL, DAO Pattern | ✅ Completed | A console-based application handling CRUD operations using raw SQL and JDBC. |

## 🛠️ Global Prerequisites
To run any project in this repo, you need:
* **Java Development Kit (JDK):** Version 8 or higher.
* **Database:** MySQL Server (8.0+ recommended).
* **IDE:** VS Code, IntelliJ IDEA, or Eclipse.
