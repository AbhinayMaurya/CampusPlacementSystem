# 🎓 Campus Placement Management System

Welcome to the **Campus Placement System** project! 

## 🚀 Project Roadmap

Each folder in this repository represents a different phase of the application's architecture.

| Phase | Technology Stack | Status | Description |
| :--- | :--- | :--- | :--- |
| **[Phase 1: JDBC](./JDBC)** | Java, MySQL, DAO Pattern | ✅ Completed | A console-based application handling CRUD operations using raw SQL and JDBC. |
| **[Phase 2: Socket](./Socket)** | Java Socket, ServerSocket, JDBC | ✅ Added | Client/server search for placement drives over TCP. |
| **[Phase 3: Servlet](./Servlets)** | Jakarta Servlet, JDBC | ✅ Completed | Existing servlet-based Campus Placement web project. |
| **[Phase 4: JSP](./JSP)** | JSP, JDBC | ✅ Added | JSP-based copy of the Campus Placement web project. |
| **[Phase 5: JSF](./JSF)** | Jakarta Faces | ✅ Added | JSF Facelets placement drive CRUD. |
| **[Phase 6: Custom Tag](./CustomTag)** | JSP Custom Tag/TLD | ✅ Added | Custom JSP tag for placement drive CRUD. |
| **[Practical 7](./Practical7)** | Hibernate XML Mapping, HQL | ✅ Added | One-table ORM mapping and HQL demo for `companies`. |
| **[Phase 7 & 8: Hibernate](./Hibernate)** | Hibernate XML Mapping, HQL | ✅ Added | Hibernate mapping and HQL DAO implementation. |
| **[Phase 9 & 10: Spring MVC](./SpringMVC)** | Spring Web MVC, JSP | ✅ Added | Spring MVC CRUD plus JSF/Spring comparison page. |

## 🛠️ Global Prerequisites
To run any project in this repo, you need:
* **Java Development Kit (JDK):** Version 8 or higher.
* **Database:** MySQL Server (8.0+ recommended).
* **IDE:** VS Code, IntelliJ IDEA, or Eclipse.
